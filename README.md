Jogo Avaliativo de RPG em texto no Portugol.  

  Este jogo utiliza a biblioteca Gráficos, para que funcione é necessário baixar os arquivos e informar corretamente os endereços na memória. Caso contrário, está disponível uma versão sem interface(JogoCompleto_Texto.por).    
  
 Alunos: Davi Rafael Schneiberg de Castro Lima e Pedro Frigo Peixoto  
 Turma: 1 TDS
